This GUI-based software allows to explore the CDISC Library over the API in a user-friendly way.
You can access all the CDISC Library content for the CDISC Standards, CDISC Biomedical Concepts and SDTM Dataset Specializations,
and navigate between items by following references just by a single click, return to prior queries etc..

In order to be able to use the software, you will need a CDISC Library API key, which you can (or should) store in a file "apikey.dat".
If the software cannot find such a file, it will add a field in the gUI for entering the key manually (e.g. copy-paste).

The software is very self-explaining, no need for an extensive manual ...

Primary goal of this software is to serve users who want to use the CDISC Library over the API, but do not know where and how to begin,
and/or are not very confident to write software that uses RESTful web services.
